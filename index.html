Что это

Блочный визуальный HTML-редактор для инструкций и статей (в т.ч. по 1С): спойлеры, предупреждения, шаги, код, таблицы, изображения, ZIP-экспорт и импорт HTML.

Быстрый старт

  • Перетащите блок из левой панели или нажмите / в редакторе.
  • Клик по блоку — выделить; чекбокс слева у блока или Ctrl+клик — несколько; в toolbar: Все / Копировать / Удалить.
  • Ctrl+A — все блоки; Delete — удалить выделенные.
  • Экспорт — HTML / HTML+CSS / ZIP с картинками. Импорт — файл или вставка кода.
  • Alt+K — палитра команд; Ctrl+Z / Ctrl+Y — отмена / повтор.

Кнопки шапки и toolbar

  • Шапка · История — Отменить, Повторить, Версии, Восстановить сессию.
  • Шапка · Вид — Тема, Команды, Клавиши.
  • Шапка · Документ — База знаний, В БЗ, Импорт, Экспорт, Передать (YouGile/почта), Очистить.
  • Toolbar — форматирование текста и операции с выделенными блоками (Все / Копировать / Удалить).

Экспорт и импорт

Экспорт отдаёт чистую разметку без UI редактора. Можно экспортировать только выделенные блоки. ZIP кладёт картинки в images/ с относительными путями.

Импорт принимает полный HTML-документ или фрагмент: body извлекается, legacy-структуры (details, warning, шаги) превращаются в блоки редактора.

База знаний

Локальная БЗ в этом браузере (без облака). Данные в localStorage.

  • База знаний в шапке — открывает страницу kb.html: дерево папок, поиск, избранное, чтение статей.
  • В БЗ — сохранить текущий документ как статью (название, папка, избранное; можно обновить существующую или сохранить как новую).
  • На странице БЗ: меню Файл (печать/PDF, JSON, настройки), кнопка История у статьи (версии), подсветка кода в просмотре.
  • Из статьи: В редактор — загрузка HTML обратно в Konstryktor для правки.
