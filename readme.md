# Визуальный HTML-редактор (Konstrycktor)

Клиентский визуальный редактор статей и документации: блоки собираются из сайдбара, правятся на холсте и экспортируются в чистый HTML. Интерфейс на русском языке. Бэкенд не обязателен — всё работает в браузере (localStorage, скачивание файлов).

---

## Назначение

Редактор рассчитан на подготовку структурированных материалов (инструкции, статьи, заметки для 1С и т.п.):

- сборка документа из готовых блоков (спойлер, предупреждение, код, таблица, FAQ, видео…);
- свободный текст и заголовки;
- настройка цветов и видимости элементов блока;
- экспорт в HTML (фрагмент или полный документ, inline/external CSS);
- импорт HTML и конвертация «старых» статей в новые макросы;
- опциональная отправка в YouGile и подготовка письма (Email).

## Возможности

### Редактирование

| Возможность | Описание |
|-------------|----------|
| Блоки из палитры | Категории: основные, контентные, полезные, технические, документация, custom HTML |
| Drag & drop | Перетаскивание блоков внутри редактора (в т.ч. во вложенные области) и шаблонов из сайдбара |
| Свободный текст | Абзацы, merge/split, слэш-меню (`/`) для быстрой вставки |
| Форматирование | Жирный, курсив, подчёркивание, зачёркивание, код, ссылка, размер/шрифт, цвета |
| Таблицы | Выбор размера, добавление/удаление строк и столбцов |
| Групповые операции | Выделение, копирование и удаление нескольких блоков |
| Настройки блока | Цвета фона/текста/рамки, видимость частей, специфичные панели (1С, FAQ, link-buttons…) |

### История и сохранность

- **Undo / Redo** (Ctrl+Z / Ctrl+Y), стек снимков HTML
- **Автосохранение** сессии в `localStorage` (crash recovery, кнопка «Восстановить»)
- **Версии** — долговременные снимки с интервалом, сравнением и восстановлением

### Экспорт и обмен

- Модалка экспорта: выделенные блоки / весь документ, режимы стилей (inline / external / none)
- Скачивание `.html` и при необходимости `article.css`
- Импорт HTML с пересборкой интерактивных блоков
- Конвертер старой разметки в новые макросы (`export/converter.js`)
- Интеграции: YouGile (задача + файлы), Email (mailto + скачивание HTML)

### UI

- Светлая / тёмная тема (системная или ручной выбор)
- Палитра команд (Ctrl/Alt+K)
- Справка по горячим клавишам
- Тосты-уведомления

## Запуск

Статический фронтенд — достаточно любого HTTP-сервера или открытия через локальный сервер (для `file://` часть API вроде fetch к YouGile может быть ограничена).

```bash
# из корня проекта
npx serve .
# или
python3 -m http.server 8080
```

Откройте `index.html` в браузере.

Дополнительно: `reg_api.html` — вспомогательная страница, связанная с API/регистрацией (не основной редактор).

## Структура проекта

```
Konstrycktor-main/
├── index.html          # Разметка редактора, модалки, подключение скриптов
├── styles.css          # Стили + CSS-переменные (светлая/тёмная тема)
├── reg_api.html        # Вспомогательная страница
├── assets/
│   ├── css/            # Доп. стили (dashboard и т.п., если используются)
│   ├── js/
│   └── img/
└── js/
    ├── core/           # Ядро состояния редактора
    │   ├── history.js      # Undo/Redo, snapshotEditor
    │   ├── autosave.js     # Автосохранение сессии
    │   └── empty-state.js  # Пустое состояние холста
    ├── drag/
    │   ├── block-drag.js   # DnD блоков на холсте
    │   └── sidebar-drag.js # DnD шаблонов из сайдбара
    ├── blocks/
    │   ├── factories.js    # create*Block, insertTemplate, insertCustomHTML
    │   └── setup.js        # setupVideoBlock, setupDownloadFileBlock
    ├── export/
    │   ├── builder.js      # Чистый HTML, документ, скачивание
    │   └── converter.js    # Конвертер старых статей
    ├── ui/
    │   ├── notifications.js
    │   └── command-palette.js
    ├── templates.js        # Палитра сайдбара (категории, иконки, loadTemplates)
    ├── editor.js           # Слушатели блоков, настройки, resize картинок
    ├── integrations.js     # YouGile + Email (IIFE)
    └── main.js             # Точка входа: тема, free-text, slash, версии, тулбар
```

### Порядок загрузки скриптов

```
core/* → ui/notifications → drag/block-drag → blocks/* → templates
→ drag/sidebar-drag → export/* → editor → integrations
→ ui/command-palette → main
```

Сейчас модули оформлены как обычные скрипты с экспортом в `window.*` (переходный вариант перед ES modules). Явный порядок в `index.html` убирает неявные зависимости вида `typeof x === 'function'`.

## Архитектура (кратко)

| Слой | Ответственность |
|------|-----------------|
| **core** | Снимки истории, автосохранение, empty-state |
| **drag** | Перетаскивание блоков и шаблонов |
| **blocks** | Фабрики разметки блоков и post-insert setup |
| **export** | Очистка HTML от UI-обвязки, сборка документа, конвертер |
| **ui** | Тосты, палитра команд |
| **templates** | Только сайдбар-палитра |
| **editor** | Поведение уже вставленных блоков (кнопки, settings, safe-edit) |
| **main** | Инициализация, free-text, slash-меню, версии, шорткаты, тема |

Документ на холсте — DOM внутри `#editor`: элементы `.block` с классами `content-*`. Экспорт клонирует DOM, снимает drag-handle / settings / contenteditable и подставляет значения CSS-переменных.

## Типы блоков

Примеры (не полный список):

- Текст, H1–H3, таблица  
- Спойлер, предупреждение, успех, заметка, нумерованный блок, код  
- Изображение, изображение с подписью, цитата  
- Видео (YouTube / RuTube), разделитель, «Скачать файл», FAQ, До/После, Автор/дата/теги  
- Кнопки-ссылки, конфигурация 1С, глоссарий, сравнение типов, заметка разработчика  
- Произвольный HTML  

Фабрики: `js/blocks/factories.js`. Интерактив после вставки (видео, файл): `js/blocks/setup.js`.

## CSS

- Файл: `styles.css` (~3.7k строк)
- Токены в `:root`: цвета, шаблонные палитры (`--tpl-*`), **spacing**, **radii**, **z-index**, `--body-chrome-bg`, `--placeholder-color`
- Тёмная тема: `body.dark-theme` переопределяет переменные (в т.ч. chrome и placeholder)
- Блоки: единый `.block` + состояния hover / selected / drag / drop

| Клавиши | Действие |
|---------|----------|

## Зависимости

Внешних npm-пакетов нет. Чистый HTML + CSS + JavaScript (ES5/ES6 в браузере).  
Интеграция YouGile ходит на `https://ru.yougile.com/api-v2` при наличии API-ключа пользователя.

---

## Рефакторинг (состояние кода)

Проведена раскладка монолита по папкам `core` / `drag` / `blocks` / `export` / `ui`, сокращены проверки `typeof … === 'function'`, CSS-переменные доведены по шкалам spacing / radii / z-index.

Возможные следующие шаги:

1. ES modules (`import` / `export`) вместо `window.*`
2. Вынести versions, slash-меню и free-text из `main.js`
3. Добить component-level dark overrides в токены
4. Тесты на export-очистку HTML и фабрики блоков
